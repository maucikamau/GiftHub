## Dijagram komponenata
Ovaj UML dijagram prikazuje arhitekturu koja se temelji na komunikaciji putem REST API-ja:
- Frontend (Vue.js): Klijentski sloj unutar web preglednika koji koristi _services_ za dohvat podataka i _router_ za upravljanje prikazima (views).
- Backend (Django): Središnji logički sloj organiziran u module (kampanje, oglasi, chat, plaćanja, korisnici, recenzije). 
- Podatkovni sloj: Uključuje PostgreSQL bazu podataka povezanu s Djangom putem ORM-a.
- Vanjski Ekosustav: Integracija s kritičnim vanjskim servisima — StreamChat (komunikacija), Google OAuth (autentifikacija) i Stripe (plaćanja).

## Dijagram razmještaja
Dijagram razmještaja na razini specifikacije prikazuje više čvorova koji opisuju web aplikaciju. Korisničko računalo PlayForward web aplikaciji pristupa s pomoću web preglednika (bez obzira na OS kojeg korisnik koristi) spaja se pomoću HTTPS protokola na web aplikaciju pohranjenu u Docker spremniku. Nadalje, vidljivo je da web aplikacija koristi četiri vanjska servisa: PostgreSQL Server za pohranu baze podataka, Stream za implementaciju chat funkcionalnosti (s kojom i korisničko računalo također komunicira), Stripe za implementaciju funkcionalnosti plaćanja dostave i OAuth 2.0 za potrebe autentifikacije. Protokol koji se koristi u svakoj vrsti komunikacije je HTTPS.
